## ⚠️ 注意事项

### 1. 权限标注

必须明确标注每个接口的权限要求：

| 权限级别 | 注解 | 说明 |
|---------|------|------|
| 无需登录 | `@Authority(AuthorityType.noRequire)` | 公开接口 |
| 需要登录 | `@Authority(AuthorityType.requireLogin)` | 登录后访问 |
| 需要管理员 | `@Authority(AuthorityType.requireAuthority)` | 仅管理员 |

### 2. 参数说明

- 路径参数：使用`{param}`格式
- 查询参数：说明是否必填、默认值
- 请求体：提供完整JSON示例

### 3. 响应格式

统一使用Result封装：

```json
{
  "code": "200",
  "msg": null,
  "data": {...}
}
```

### 5. 代码示例

- 使用Vue 3 Composition API语法
- 包含完整的import语句
