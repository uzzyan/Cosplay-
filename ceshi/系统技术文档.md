### 2.2 请求处理流程

```
用户操作
  ↓
① 前端Vue组件发起Axios请求
  ↓
② Axios请求拦截器添加Token到请求头
  ↓
③ 请求发送到后端 (通过devServer代理)
  ↓
④ Spring Boot接收请求
  ↓
⑤ JwtInterceptor.preHandle() 验证Token
   ├─ 检查@Authority注解
   ├─ 从请求头提取Token
   ├─ 从Redis查询用户信息
   ├─ 验证JWT签名
   ├─ 存入ThreadLocal (UserHolder)
   └─ 重置Token过期时间 (180分钟)
  ↓
⑥ AuthorityInterceptor 验证权限
   ├─ @Authority(requireAuthority) → 检查role=admin
   ├─ @Authority(requireLogin) → 检查已登录
   └─ @Authority(noRequire) → 放行
  ↓
⑦ Controller接收请求参数
  ↓
⑧ Service处理业务逻辑
   ├─ 查询Redis缓存 (如商品详情)
   ├─ 缓存未命中 → 查询MySQL
   ├─ 回写Redis缓存
   └─ 执行CRUD操作
  ↓
⑨ Mapper执行SQL语句
  ↓
⑩ 返回Result统一响应对象
  ↓
⑪ Axios响应拦截器处理
   ├─ 检查code='401' → 清除登录信息
   ├─ 检查code='200' → 返回data
   └─ 错误处理 → 显示ElMessage
  ↓
⑫ Vue组件更新视图
```

## 4. 核心功能模块

### 4.1 用户认证模块

#### 4.1.1 登录流程

**前端流程 (Login.vue):**
```javascript
1. 用户输入用户名、密码
2. 前端使用js-md5对密码进行MD5加密
   const md5Password = md5(password)
3. 发送POST请求到 /login
   { username: "user001", password: "md5加密后的密码" }
4. 接收响应,保存用户信息到localStorage
   localStorage.setItem('user', JSON.stringify(userData))
5. 跳转到首页或之前访问的页面
```

**后端流程 (UserService.login):**
```java
1. 根据username查询数据库
2. 验证密码(双重加密机制)
   - 前端传来的是MD5密码
   - 与数据库BCrypt密码比对
   - PASSWORD_ENCODER.matches(md5Password, storedPassword)
3. 密码匹配成功
   - 生成JWT Token
   - 存入Redis (key: "user:token:{token}", TTL: 180分钟)
   - 返回UserDTO (包含Token)
4. 密码匹配失败 → 抛出异常
```

#### 4.1.2 密码加密机制

**加密流程:**
```
用户输入明文密码
  ↓
前端: md5(明文密码) → MD5哈希值
  ↓
后端: BCrypt(MD5哈希值) → BCrypt哈希值
  ↓
存储到数据库 sys_user.password 字段
```

**验证流程:**
```
用户输入明文密码
  ↓
前端: md5(明文密码) → MD5哈希值
  ↓
后端: BCrypt.matches(MD5哈希值, 数据库BCrypt值)
  ↓
返回验证结果 (true/false)
```

**密码规则:**
```java
// 正则: 6-12位,包含字母、数字、特殊符号
^(?=.*[A-Za-z])(?=.*\d)(?=.*[!@#$%^&*()_+\-=\[\]{}|;:,.<>?])[A-Za-z\d!@#$%^&*()_+\-=\[\]{}|;:,.<>?]{6,12}$
```

#### 4.1.3 Token管理

**Token生成 (TokenUtils.genToken):**
```java
public static String genToken(String userId, String username){
    String token = JWT.create()
            .withAudience(userId)  // Payload存储userId
            .sign(Algorithm.HMAC256(jwtSecret));  // HMAC256签名
    return token;
}
```

**Token存储:**
```
Redis Key: "user:token:{token}"
Redis Value: User对象 (JSON序列化)
TTL: 180分钟
```

**库存扣减:**
```sql
UPDATE good_standard 
SET store = store - #{count} 
WHERE good_id = #{goodId} 
  AND standard = #{standard}
  AND store >= #{count}
```

#### 4.2.3 商品缓存策略

**Redis缓存配置:**
```
Key: "good:{id}"
TTL: 30分钟
Value: Good对象
```

**缓存读取流程:**
```java
1. 尝试从Redis获取
2. 缓存命中 → 返回并刷新TTL
3. 缓存未命中 → 查询MySQL
4. 写入Redis缓存
5. 返回结果
```

**缓存清除时机:**
- 商品编辑时
- 商品删除时
- 订单支付时(同步更新销量)

## 7. 认证与授权机制

### 7.1 JWT Token认证

**Token生成:**
```java
JWT.create()
   .withAudience(userId)  // Payload: userId
   .sign(Algorithm.HMAC256(jwtSecret))  // HMAC256签名
```

**Token验证流程 (JwtInterceptor):**
```java
1. 从请求头提取Token
2. 检查@Authority注解
3. 从Redis查询用户信息
4. 验证JWT签名
5. 存入ThreadLocal (UserHolder)
6. 重置Token过期时间(180分钟)
```

### 7.2 自定义权限注解

```java
@Authority(AuthorityType.noRequire)      // 不需要登录
@Authority(AuthorityType.requireLogin)   // 需要登录
@Authority(AuthorityType.requireAuthority) // 需要管理员权限
```

### 7.3 ThreadLocal用户存储

```java
// 保存用户
UserHolder.saveUser(user);

// 获取当前用户
User currentUser = TokenUtils.getCurrentUser();

// 请求完成后清除
UserHolder.removeUser();
```

### 7.4 前端路由守卫

```javascript
router.beforeEach(async (to, from, next) => {
  // 后台管理页面: 检查role=admin
  if (to.meta.requireAuth === true) {
    if (role !== 'admin') {
      ElMessage.error('您没有权限访问该页面')
      next("/")
    }
  }
  // 前台页面: 检查已登录
  else if (to.meta.requireLogin === true) {
    if (!localStorage.getItem('user')) {
      next('/login')
    }
  }
})
```

## 11. 安全机制

### 11.1 密码安全

**双重加密:**
```
明文密码 → MD5(前端) → BCrypt(后端) → 数据库
```

**优势:**
- 即使数据库泄露,攻击者也无法直接获取明文密码
- BCrypt自带salt,防止彩虹表攻击
- MD5作为第一层加密,增加破解难度

### 11.2 Token安全

**Token存储:**
- 前端: localStorage (加密存储)
- 后端: Redis (180分钟TTL)

**Token验证:**
- 每次请求验证JWT签名
- Redis中查询用户信息
- 动态重置TTL(活跃用户自动续期)

**安全防护:**
- Token泄露后,180分钟自动失效
- 用户重新登录后,旧Token失效
- 敏感操作二次验证

### 11.3 权限控制

**三层防护:**
1. **前端路由守卫**: 阻止未授权访问
2. **JWT拦截器**: 验证Token有效性
3. **权限拦截器**: 检查角色权限

**权限注解:**
```java
@Authority(noRequire)      // 公开接口
@Authority(requireLogin)   // 登录用户
@Authority(requireAuthority) // 管理员
```

### 11.4 SQL注入防护

- 使用MyBatis-Plus参数化查询
- 禁止拼接SQL语句
- 使用`#{}`而非`${}`

### 11.5 XSS防护

- 前端输入框过滤特殊字符
- 后端参数验证
- 输出转义
