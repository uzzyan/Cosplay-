## 4. 前端功能验证
- **首页访问**: 访问 `http://localhost:9192` 成功，页面渲染正常。
- **跨域配置**: `vue.config.js` 配置端口 9192，后端 `UserController` 已添加 `@CrossOrigin`，API 请求无跨域错误。
- **请求封装**: `request.js` 中 `baseURL` 设置为 `http://localhost:9191`，拦截器正常添加 Token。

## 5. 关键修复验证
- **类丢失问题**: 重新编译后，`AuthorityInterceptor$1` 类丢失导致的 500 错误已解决。
- **库存扣减**: `StandardMapper` 中的 SQL 已更新为原子扣减，防止超卖。

## 6. 结论
系统集成测试通过，核心链路（前端页面 -> API请求 -> 数据库查询）畅通。前后端服务均能稳定运行。
