# 数据库表结构文档

## 5. 评论表

评论表用于存储用户对商品的评价信息,包括评论内容、用户ID、商品ID、评论时间以及商家回复等内容。其结构如表 5-1 所示。

### 表 5-1 评论表

| 字段 | 字段类型 | 字段长度 | 字段说明 | 字段约束 |
|------|----------|----------|----------|----------|
| id | bigint | 10 | 主键,自增 | 主键 |
| content | varchar | 1600 | 评论内容 | 非空 |
| user_id | bigint | 10 | 用户ID | 外键 |
| good_id | bigint | 10 | 商品ID | 外键 |
| create_time | varchar | 50 | 评论时间 | 非空 |
| reply | varchar | 1600 | 商家回复 | 可为空 |

## 附录:SQL 建表语句

### 评论表 SQL

```sql
CREATE TABLE `comment` (
  `id` bigint NOT NULL AUTO_INCREMENT COMMENT '主键,自增',
  `content` varchar(1600) NOT NULL COMMENT '评论内容',
  `user_id` bigint DEFAULT NULL COMMENT '用户ID',
  `good_id` bigint DEFAULT NULL COMMENT '商品ID',
  `create_time` varchar(50) NOT NULL COMMENT '评论时间',
  `reply` varchar(1600) DEFAULT NULL COMMENT '商家回复',
  PRIMARY KEY (`id`) USING BTREE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci COMMENT='评论表';
```

### 留言表 SQL

```sql
CREATE TABLE `message` (
  `id` bigint NOT NULL AUTO_INCREMENT COMMENT '主键,自增',
  `user_id` bigint DEFAULT NULL COMMENT '用户ID',
```

## 字段说明补充

### 评论表字段说明

- **content**: 用户对商品的评价内容,支持最多1600个字符
- **user_id**: 发表评论的用户ID,关联 sys_user 表
- **good_id**: 被评论的商品ID,关联 good 表
- **create_time**: 评论创建时间,格式: yyyy-MM-dd HH:mm:ss
- **reply**: 商家对评论的回复内容

### 留言表字段说明

- **title**: 留言标题,简要描述留言主题
- **content**: 留言详细内容
- **contact**: 用户联系方式(电话/邮箱等)
- **custom_intent**: 是否有定制意向,0表示无,1表示有
- **reply**: 管理员对留言的回复
- **reply_time**: 管理员回复时间

### 售后服务表字段说明

- **order_no**: 关联的订单编号
- **type**: 售后类型,如:退货、换货、退款等
- **reason**: 申请售后的原因说明
- **status**: 处理状态,如:待处理、处理中、已完成、已拒绝等
- **handle_time**: 管理员处理售后的时间

### 系统公告表字段说明

- **title**: 公告标题,简要概括公告内容
- **content**: 公告详细内容,支持富文本
- **create_time**: 公告发布时间
